## 📂 Repository Structure

This repository is organized into **week-by-week directories** that align with the concepts taught in class.

Each directory may include:

- ✅ **Coding Examples**  
  Illustrative code snippets demonstrating key concepts.

- 📝 **Assignment Questions**  
  Practice problems to be solved as part of your coursework.  
  Format: `week<number>_day<number>_assignments.md`

- 📚 **Case Studies**  
  Real-world scenarios with questions and solutions to deepen your understanding.
